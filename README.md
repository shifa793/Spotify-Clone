# 🎵 Spotify Clone

A simple **Spotify Clone UI** created using **HTML and CSS**. This project is designed to practice frontend development and recreate the basic layout and look of Spotify.

## 🚀 Features

* Spotify-inspired user interface
* Sidebar navigation
* Playlist section
* Music cards
* Bottom music player
* Clean and simple layout
* Responsive design

## 🛠️ Technologies Used

* HTML5
* CSS3
